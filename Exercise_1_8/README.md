# Molecular & Materials Modeling Workflow: UO2I2(OH2)2 Complex

This repository contains the computational workflow and geometry optimization steps for the diiododioxouranium(VI) dihydrate complex, $\text{UO}_2\text{I}_2(\text{OH}_2)_2$.

## Workflow Summary
1. **Initial Geometry Optimization**: Conducted using the **MACE** machine-learned interatomic potential via Python ASE framework.
2. **DFT Geometry Optimization & Energy**: Performed with **NWChem** utilizing Density Functional Theory (DFT/B3LYP) combined with **Stuttgart RLC Effective Core Potentials (ECP)** for scalar relativistic treatment of Uranium and Iodine.

## Directory Structure
- `run_mace.py`: Python script for initial MACE optimization.
- `UO2I2_nwchem.nw`: NWChem input file for DFT optimization.
- `run_nwchem.out`: Raw output file generated by NWChem.
- `UO2I2_dft_optimized.xyz`: Final optimized molecular coordinates (11 atoms).

## Execution Commands

### Step 1: Initial MACE Optimization
```bash
python3 run_mace.py

### Step 2: NWChem DFT Geometry Optimization

export NWCHEM_BASIS_LIBRARY=$CONDA_PREFIX/share/nwchem/libraries/
nwchem UO2I2_nwchem.nw > run_nwchem.out

### Step 3: Extracting Final XYZ Coordinates

sed -n '11848,11858p' run_nwchem.out | awk '{printf "%-3s %12.6f %12.6f %12.6f\n", $2, $4, $5, $6}' > coords.tmp
echo -e "11\nUO2I2(OH2)2 DFT Optimized Structure" > UO2I2_dft_optimized.xyz
cat coords.tmp >> UO2I2_dft_optimized.xyz
rm coords.tmp

### Structure Visualization

pymol UO2I2_dft_optimized.xyz
