## Overview
Molecular Dynamics thermal expansion analysis evaluating temperature-dependent lattice parameters ($100\text{ K} - 700\text{ K}$) and calculating the linear thermal expansion coefficient ($\alpha = \frac{1}{a_0} \frac{da}{dT}$).
