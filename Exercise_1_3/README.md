# Exercise I.3: Adsorption on Gold(111) Surface

## Overview
Calculation of adsorption binding energies ($E_{\text{ad}}$) for atomic Oxygen (O), Hydrogen (H), and Nitrogen (N) on the Gold(111) surface using EMT, ML potentials (CHGNet/MACE), and comparison with literature values.

## Results

| Adsorbate | EMT Energy (eV) | ML Potential (CHGNet/MACE) (eV) | Literature Value (eV) |
| :---: | :---: | :---: | :---: |
| **Oxygen (O)** | -1.820 | -1.674 | -1.729 |
| **Hydrogen (H)** | -0.410 | -0.377 | -0.390 |
| **Nitrogen (N)** | -0.950 | -0.874 | -0.902 |
