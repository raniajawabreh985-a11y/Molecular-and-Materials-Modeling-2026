# Exercise I.2: Atomization Energy Calculation

## Overview
Calculation of atomization energies ($E_{atomization} = 2 E_{atom} - E_{molecule}$) for diatomic molecules ($H_2$, $N_2$, $O_2$) using the ASE EMT calculator.
